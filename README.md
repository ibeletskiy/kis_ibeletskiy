### Задача № 4

Для быстрой проверки на загруженных тестах нужно запустить `./run.sh`.

Для компиляции `g++ -std=c++20 -Ofast -o comparator comparator.cpp`
Для запуска `./comparator -A "example_A" -B "example_B" ...`

Параметр `-p` отвечает за учитываемый процент.
Кроме того есть параметр `-t`, ограничивающий количество используемых тредов.

Для сравнения было принято решения сделать адаптивное разбиение на блоки в зависимости от размеров файлов сравниваемой пары. 
Кроме того хотелось написать также дополнительный вариант сравнения в виде дополнительной проверки LCS внутри некоторой части блоков после подсчета на их хешах, чтобы уменьшить вероятность ошибки, но не уверен что успел это реализовать. В теории также можно было бы брать случайные подпоследовательности из меньшего файла и использовать их для проверки.
